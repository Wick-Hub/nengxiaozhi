# 知识收集清单（各部门）

> 用途：① 发给各部门联络员的知识收集任务单；② 知识建设进度台账。
> 优先级：**P0** = 演示与验收必需；**P1** = 高频咨询内容；**P2** = 全量覆盖。
> 联络员、截止日期由项目组与各部门商定后填写。

## 填写与交付要求

1. 格式：优先 md / docx / pdf；表格数据用 xlsx；FAQ 按《FAQ问答对规范》模板整理
2. 命名：`主题.md`，放入对应 `部门/类型` 目录
3. 每份文件须填写 frontmatter 元数据（见《知识类型标准》）
4. 脱敏：删除个人信息与内部敏感数据
5. 标注来源文号与内容基准日期
