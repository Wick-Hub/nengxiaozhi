# 固定资产处置管理办法（节选）

## 第一章 总则

第一条 为规范学校固定资产处置行为，防止国有资产流失，根据国家和陕西省有关规定，结合学校实际，制定本办法。

第二条 本办法适用于全校各类占用、使用学校固定资产的单位和个人。

第三条 本办法所称固定资产处置，是指学校对占有、使用的固定资产进行产权转让或注销产权的行为，包括报废、报损、出售、出让、转让、对外捐赠、无偿调拨（划转）等。

## 第二章 处置范围

第四条 符合下列情形之一的固定资产可申请处置：

1. 达到或超过规定使用年限，且无法继续满足工作需要的；
2. 因技术原因确需淘汰，且无法改造利用的；
3. 因单位分立、合并、撤销、隶属关系改变需要转移产权的；
4. 盘亏、非正常损失需报废、报损的；
5. 依照国家有关规定需要进行处置的其他情形。

## 第三章 审批权限

第五条 固定资产处置按资产原值实行分级审批：

| 资产原值（单件/批量） | 审批层级 |
| --- | --- |
| 5 万元以下 | 使用单位负责人 + 国有资产管理处 |
| 5 万-50 万元 | 国有资产管理处 + 分管校领导 |
| 50 万元以上 | 校长办公会审议，报上级主管部门备案或审批 |

第六条 未经批准，任何单位和个人不得擅自处置学校固定资产。

## 第四章 处置程序

第七条 固定资产处置按以下程序办理：

1. 使用单位填写《固定资产处置申请表》，附技术鉴定意见；
2. 单位负责人签字后报国有资产管理处审核；
3. 按审批权限逐级审批；
4. 审批通过后，由国有资产管理处统一组织处置（报废资产按规定移交有资质的回收企业）；
5. 财务处凭处置批复和回收凭证核销账务。

第八条 固定资产处置收入按照"收支两条线"原则管理，扣除相关税费后全部上缴学校财务，任何单位不得截留、挪用。
