# FAQ 问答对规范

> FAQ 是召回准确率最高的知识形态：一条标准问答对的效果远优于从政策文件里切出来的片段。招生、财务等高频咨询场景优先按本规范人工整理。

## 一、字段定义

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| q（标准问） | ✅ | 用师生最常用的完整问句表述，口语化优先 |
| variants（同义问法） | ✅ | 2-3 条，覆盖不同问法、简称、口语表达 |
| a（答案） | ✅ | ≤300 字，结论先行 |
| dept / ktype / visible_roles / status / updated / source | ✅ | 同《知识类型标准》 |

## 二、Markdown 格式（单文件多条，推荐）

```markdown
---
title: 本科招生咨询常见问题
dept: 本科生招生办
ktype: faq
visible_roles: 访客, 本科生
status: 已审核
updated: 2026-06-30
source: 招生办咨询电话记录整理
---

# 本科招生咨询常见问题

## 问：可以转专业吗？

答：可以。学校实行宽松的转专业政策，学生入学后在大一第一学期末可申请转专业，转出不设门槛（有特殊招生限制的专业除外），具体以当年教务处通知为准。

同义问法：进去以后能换专业吗；转专业有什么条件；大几可以转专业。
```

要点：一个 `## 问：` = 一条知识切片（引擎按二级标题切分，问题与答案、同义问法保持在一个切片内）。

## 四、xlsx 格式（部门习惯表格交付时）

首行为表头，固定三列：`问题 | 答案 | 同义问法`，同义问法用分号分隔。整表会被解析为表格知识。

## 五、编写要点

1. **标准问选最高频问法**：优先采用咨询记录中真实出现过的问法，而非文件原文表述
2. **变体问法覆盖三类差异**：不同主体（我/学生/研究生）、不同动词（办/申请/开）、不同粒度（空调/宿舍空调/寝室空调）
3. **答案结构**：第一句给结论 → 关键数字 → 办理渠道或链接
4. **宁缺毋滥**：不确定的内容写"以XX部门最新通知为准"，不猜测
