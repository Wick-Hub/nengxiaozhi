# 本科招生咨询常见问题

## 问：学校今年的录取分数线是多少？

答：录取分数线在各省录取工作结束后才会确定，无法提前提供。可参考近三年各省份录取分数统计（本科招生网"历年分数"栏目）；填报志愿时建议重点参考位次而非绝对分数。招生咨询电话：029-8558XXXX。

同义问法：多少分能上西安科技大学；贵校分数线是多少；去年的录取线是多少。

## 问：可以转专业吗？

答：可以。学校实行宽松的转专业政策，学生入学后在大一第一学期末可申请转专业，转出不设门槛（有特殊招生限制的专业除外），具体以当年教务处通知为准。

同义问法：进去以后能换专业吗；转专业有什么条件；大几可以转专业。

## 问：学生宿舍是几人间？有空调和独立卫生间吗？

答：本科生宿舍以 4-6 人间为主，所有宿舍均配备空调，大部分宿舍有独立卫生间。宿舍由学校统一分配，原则上同专业同班优先安排同一宿舍。

同义问法：住宿条件怎么样；宿舍有没有空调；几人一间宿舍。

## 问：学费和住宿费标准是多少？

答：普通理工类专业学费 4500-6380 元/年，文史类专业 3500-4500 元/年，艺术类专业约 11000 元/年；住宿费 800-1200 元/年（按宿舍类型）。具体以入学须知及陕西省物价部门核定标准为准。

| 类别 | 收费标准（元/年） |
| --- | --- |
| 理工类专业 | 4500-6380 |
| 文史类专业 | 3500-4500 |
| 艺术类专业 | 11000 |
| 住宿费 | 800-1200 |

同义问法：一年学费多少钱；学费贵不贵；住宿费是多少。

## 问：录取通知书什么时候寄发？

答：各省录取结束后 3 个工作日内，学校统一通过 EMS 寄发录取通知书，考生可在本科招生网"录取查询"栏目查询邮寄单号。

同义问法：通知书什么时候到；怎么查询通知书物流；录取结果什么时候公布。

## 问：新生可以提前到校报到吗？

答：原则上不建议提前到校。确有特殊原因需提前到校的，请提前与所在学院辅导员联系，学校可协助安排临时住宿。正式报到日当天，学校在火车站、高铁站设有迎新接待点。

同义问法：能提前几天去学校吗；提前到校住哪里；报到有人接站吗。
